🛡️ Odoo Security Scanner Suite

Essential Free Toolkit for Securing Your Odoo Environment

Perform critical configuration checks and system audits directly from the backend — no coding or CLI required.

📘 Overview

The Odoo Security Scanner Suite is a free, lightweight module developed by Odevmo to help you validate security-related settings in your Odoo environment. From access control to HTTPS to logging, this tool provides essential checks with zero configuration needed.

  • ✔️ Fast, read-only scans of your configuration
  • ✔️ One-click UI interface for quick assessments
  • ✔️ No external dependencies

🔍 Core Checks

  • Master Password Validation
  • HTTPS Enforcement
  • Access Rule Verification
  • Logging Configuration Check
  • Database Filtering Status
  • Database Listing Visibility

Results are displayed with pass/fail icons and helpful summaries.

🖼️ Screenshots

Main scanner results view with verdicts

🚀 Simple to Use

  • No configuration required — install and click "Scan"
  • Inline summaries explain each finding
  • Secure-by-default: read-only, no writes or mutations

📦 Installation

  • Extract the security_scanner_suite folder to your Odoo addons/ path
  • Restart the Odoo server
  • Install it from the Odoo Apps menu

📈 Roadmap

  • Scheduled scans with daily/weekly intervals
  • Email notifications for critical config gaps
  • More system-level diagnostics (e.g. file permissions, dependencies)
